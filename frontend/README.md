# Frontend — VeriBrain

React + TypeScript frontend for the VeriBrain query console, policy inspector, and audit explorer.

## Structure

- Query Console — natural-language query input with grounded answer display.
- Policy Inspector — visible ALLOW/DENY cards with reason, permission source, ACL version.
- Audit Explorer — queryable tamper-evident audit trail.
- Demo Persona Switcher — switch between Alice/Engineer, Bob/Contractor, Compliance Officer.
